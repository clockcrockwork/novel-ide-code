# プレーンテキスト変換・文字数カウントルール

## toPlainText() の変換ルール（src/lib/plainText.js）

`.txt` エクスポートに使用する。

| 記法 | 変換後 | 理由 |
|------|--------|------|
| `// コメント` | 除去 | 執筆メモ、出力対象外 |
| `/* コメント */` | 除去 | インライン注釈、出力対象外 |
| `%% アノテーション %%` | 除去 | ハイライトメモ、出力対象外 |
| `# 見出し` | 見出しテキストのみ | 記号を除去、文章は保持 |
| `**ボールド**` | ボールドテキストのみ | 記号を除去、文章は保持 |
| `{漢字\|かんじ}` | `漢字（かんじ）` | 読み仮名を括弧付きで保持 |
| `---`（水平線） | `---` のまま | シーン区切り記法として保持 |
| 3行以上の空行 | 最大2行に正規化 | 余分な空白の除去 |

## toSiteText() の変換ルール（src/lib/plainText.js）

`MultiReplaceMod` のコピー/DL 時に使用する。`applyBase()` を適用した後、サイト別のルビ形式に変換する。

| 記法 | 変換後 | 条件 |
|------|--------|------|
| `// コメント` | 除去 | 常時 |
| `/* コメント */` | 除去 | 常時 |
| `%% アノテーション %%` | 除去 | 常時 |
| `# 見出し` | 見出しテキストのみ | 常時 |
| `**ボールド**` | ボールドテキストのみ | 常時 |
| 3行以上の空行 | 最大2行に正規化 | 常時 |
| `{漢字\|かんじ}` | サイト別形式に変換 | `rubyFormat` が設定済みの場合 |
| `{漢字\|かんじ}` | そのまま | `rubyFormat` が `'none'` / 未設定の場合 |

`RUBY_PRESETS`（`src/lib/plainText.js`）にプリセット一覧を定義している。

| プリセット | テンプレート | サイト例 |
|-----------|-------------|---------|
| `kakuyomu` | `｜{base}《{reading}》` | カクヨム / なろう / ハーメルン |
| `pixiv` | `[[rb:{base} > {reading}]]` | pixiv |
| `novelup` | `{base}《{reading}》` | ノベルアップ+ |
| `custom` | ユーザー入力テンプレート | 任意（`{base}` / `{reading}` をプレースホルダーとして使用） |

## toWordCountText() の変換ルール（src/lib/plainText.js）

`WordCountMod` の文字数カウントに使用する。`toPlainText()` と同じだがルビ扱いが異なる。

| 記法 | 変換後 | 理由 |
|------|--------|------|
| `{漢字\|かんじ}` | `漢字` | 読み仮名は補助情報、本文字数のみ計上 |
| その他 | `toPlainText()` と同じ | - |

## toSiteWordCountText() の変換ルール（src/lib/plainText.js）

`WordCountMod` の投稿サイト向け文字数カウントに使用する。`applyBase()` のみを適用し、ルビ記法・名前タグ等の記法文字を文字数に含める。

| 記法 | 変換後 | 理由 |
|------|--------|------|
| `{漢字\|かんじ}` | `{漢字\|かんじ}` のまま | 投稿サイトは記法文字を含めてカウントするため |
| その他 | `toWordCountText()` と同じ | - |

## 文字数カウントルール（WordCountMod.jsx）

`toWordCountText()` または `toSiteWordCountText()` 後のテキストで空白（`\s`）を除いた文字数を表示する。

| 記法 | 本文モード | 投稿モード |
|------|-----------|-----------|
| `{漢字\|かんじ}` | 2文字（本文のみ） | 9文字（記法込み） |
| コメント・アノテーション | 0文字 | 0文字 |
| 見出し記号 `#` | 0文字 | 0文字 |
| ボールド記号 `**` | 0文字 | 0文字 |
| `---`（水平線） | 3文字 | 3文字 |

- 選択テキストは TipTap の `textBetween()` でプレーンテキスト取得済みのため
  `toWordCountText()` / `toSiteWordCountText()` を適用しない（二重処理になる）
  - `plainTextToPmJson()` が `{base|reading}` を `atom: true` の `ruby` ノードに変換するため、
    `textBetween()`（`leafText` 未指定）は ruby を文字として出力しない。
    変換関数を適用しても ruby については効果がなく、他の記法に対して誤処理が生じる可能性がある
- モード選択は `uiStore` の `wordCountMode`（`'offline'` | `'site'`）に persist される

## stripComments() の動作

- `// テキスト`（行末まで）を除去
- `/* テキスト */` を除去（複数行・アスタリスク含む内容も対応: `[\s\S]*?`）
- `markdown.js` のプレビュー前処理でも共用（重複排除済み）

## 変換対象外

| 対象 | 理由 |
|------|------|
| `---` → `<hr/>` | `markdown.js` 経由のプレビュー・PDF 用。`toPlainText()` は対象外 |
| `{base\|reading}` → `<ruby>` | `markdown.js` 経由の HTML レンダリング用。`toPlainText()` は対象外 |
